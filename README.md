# Task Manager REST API

## Overview

A Spring Boot REST API for managing tasks with CRUD operations.

## Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- Oracle Database
- Flyway
- JUnit 5
- Mockito
- Postman
- Git & GitHub

## Features

- Create Task
- Get All Tasks
- Get Task By ID
- Update Task
- Delete Task
- Validation
- Exception Handling
- Unit Testing

## API Endpoints

### Create Task

POST /tasks

### Get All Tasks

GET /tasks

### Get Task By ID

GET /tasks/{id}

### Update Task

PUT /tasks/{id}

### Delete Task

DELETE /tasks/{id}
